# 워크북 안내

이 워크북은 P&ID를 처음 보는 분이 Claude Code나 Codex와 함께 실제 도면을 읽어 보는 실습 안내서입니다. 예시 도면 한 장과 같은 질문을 계속 사용하여, 전체에서 위치를 찾고 작은 태그를 확인한 뒤 근거를 남기는 과정을 따라갑니다.

## 시작 전에 준비할 것

| 참여 방법 | 준비 |
|---|---|
| 사이트에서 내용을 읽고 준비된 결과를 확인합니다. | 별도 준비가 필요하지 않습니다. |
| 명령을 직접 실행해 결과를 만들어 봅니다. | 실습 키트를 내려받은 뒤, 사용할 Claude Code 또는 Codex에 로그인합니다. |

[실습 키트 ZIP 내려받기](/pnid-understanding-bootcamp/downloads/pnid-ai-workbook-kit.zip)

압축을 풀고 터미널에서 `pnid-ai-workbook-kit` 폴더로 이동합니다. 이후 단원에 나오는 `./scripts/...` 명령과 `실습자료/...` 경로는 이 폴더 안에서 실행하고 찾습니다.

## 중심 질문과 기준 답안

> 이 P&ID에서 `RECEPTION BIN 2`의 A측 하부 출구와 연결된 `VIBRO FEEDER #C`를 찾아 주세요. Reception Bin 2의 장비 태그, A측 밸브 번호, Feeder #C의 장비 태그, 연결된 전동기의 심벌 표기와 태그를 적어 주세요.

| 확인 항목 | 기준 답안 |
|---|---|
| Reception Bin 2 장비 태그 | `11520-M-SI-04` |
| A측 하부 출구 밸브 | `V186` |
| Vibro Feeder #C 장비 태그 | `11520-M-VB-03C` |
| Feeder #C 전동기 | `EM / 11520-E-MT-18` |

연결 순서는 `RECEPTION BIN 2 → A측 하부 출구 → V186 → VIBRO FEEDER #C → EM / 11520-E-MT-18`입니다.

## 워크북 진행 순서

| 순서 | 단원 | 직접 해보는 일 | 남는 결과 |
|---:|---|---|---|
| 1 | P&ID 입문 | 제목란, 범례, 장비, 선과 태그를 실제 도면에서 찾습니다. | 도면을 읽는 기본 순서 |
| 2 | 첫 번째 실제 실험 | 전체 이미지와 부분 확대 이미지를 모델에 입력해 결과를 비교합니다. | 모델별 실제 답변과 점수 |
| 3 | 이미지 입력 전략 | 전체에서 위치를 찾고 필요한 구역을 확대합니다. | 질문에 맞는 이미지 선택 기준 |
| 4 | OCR와 에이전트 검색 | 도면의 문자를 검색하고 검색 결과를 원본에서 확인합니다. | 검색 가능한 PDF와 문자 위치 |
| 5 | AI 답변을 원본 위치와 연결하기 | 답의 근거가 도면 어디에 있는지 표시합니다. | 다시 찾을 수 있는 근거 위치 |
| 6 | P&ID 데이터 정리 | 도면 기본정보, 큰 구역과 주요 태그를 JSON으로 기록합니다. | 검색 가능한 도면 색인 |
| 7 | AI에게 도면 작업 맡기기 | 목표·입력·규칙·출력·완료 조건을 하나의 요청으로 작성합니다. | 재사용 가능한 업무 요청문 |

## 이 워크북에서 사용하는 파일

| 파일 | 역할 |
|---|---|
| `실습자료/이미지/전체-도면.png` | 도면 전체 구조와 질문 구역의 위치를 찾습니다. |
| `실습자료/이미지/feeder-c-확대.png` | Feeder #C 주변의 작은 태그를 확인합니다. |
| `실습자료/근거-이미지/feeder-c-근거.png` | 답의 근거 위치가 어디인지 확인합니다. |
| `실습자료/ocr/검색가능한-pnid.pdf` | OCR 문자 검색을 실습합니다. |

공개 이미지에는 회사명, 로고, 주소와 작성자 정보가 보이지 않도록 마스크가 적용되어 있습니다. PDF 변환이나 이미지 분할부터 시작하지 않고 준비된 파일로 바로 실습할 수 있습니다.

## 결과를 볼 때 기억할 기준

| 확인할 질문 | 이유 |
|---|---|
| 도면에서 직접 읽은 문자열인가요? | 모델의 해석과 실제 표기를 구분합니다. |
| 어떤 선을 따라 연결을 확인했나요? | 가까이 있는 다른 장비의 태그와 섞이지 않게 합니다. |
| 원본의 어느 위치에서 다시 확인할 수 있나요? | 다른 사람이 같은 판단을 검토할 수 있게 합니다. |
| 읽지 못한 값을 추측하지 않았나요? | 자연스럽지만 근거 없는 답을 막습니다. |

이제 [P&ID 입문](01-pnid-기초.md)에서 AI를 사용하기 전에 사람이 도면을 어떤 순서로 읽는지 먼저 살펴봅니다.
