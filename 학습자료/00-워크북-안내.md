# 워크북 안내

이 워크북은 P&ID를 처음 접하는 분을 위한 실습 안내서입니다. Claude Code나 Codex와 예시 도면 한 장을 함께 읽습니다. 도면 전체에서 위치를 찾고 작은 태그를 확인한 뒤, 판단 근거를 남기는 과정을 같은 질문으로 반복합니다.

## 시작 전에 준비할 것

> 이 워크북에서는 ZIP에 포함된 교육용 샘플만 사용하세요. 실제 사내 도면과 업무 문서는 회사가 승인한 AI 환경과 보안 정책을 확인하기 전에는 업로드하지 마세요.

| 참여 방법 | 준비 |
|---|---|
| 기본 경로: 사이트에서 읽고 앱에 이미지를 첨부합니다. | Codex 또는 Claude 앱에 로그인합니다. |
| 선택 경로: 명령을 직접 실행합니다. | 실습 키트와 Claude Code 또는 Codex CLI가 필요합니다. |
| 고급 선택 경로: OCR·좌표 파일을 만듭니다. | 해당 단원에서 안내하는 추가 프로그램이 필요합니다. |

[실습 키트 ZIP 내려받기](/pnid-understanding-bootcamp/downloads/pnid-ai-workbook-kit.zip)

압축을 푼 뒤 터미널에서 `pnid-ai-workbook-kit` 폴더로 이동하세요. 이후 단원의 `./scripts/...` 명령은 이 폴더에서 실행합니다. `실습자료/...`로 시작하는 파일도 같은 폴더 안에 있습니다.

처음이라면 터미널을 열지 않아도 됩니다. Codex 또는 Claude에서 새 작업을 열고 `실습자료/이미지/전체-도면.png`를 첨부한 뒤 `실습자료/프롬프트/기본-질문.txt`의 전체 내용을 같은 입력창에 붙여 넣으세요. 표 형식의 네 항목이 나오면 실행에 성공한 것입니다. 조건을 바꿀 때마다 이전 답변의 영향을 피하기 위해 새 작업에서 시작합니다.

## 중심 질문과 기준 답안

> 이 P&ID에서 `RECEPTION BIN 2`의 A측 하부 출구와 연결된 `VIBRO FEEDER #C`를 찾아 주세요. Reception Bin 2의 장비 태그, A측 밸브 번호, Feeder #C의 장비 태그, 연결된 전동기의 심벌 표기와 태그를 적어 주세요.

| 확인 항목 | 기준 답안 |
|---|---|
| Reception Bin 2 장비 태그 | `11520-M-SI-04` |
| A측 하부 출구 밸브 | `V186` |
| Vibro Feeder #C 장비 태그 | `11520-M-VB-03C` |
| Feeder #C 전동기 | `EM / 11520-E-MT-18` |

연결 순서는 `RECEPTION BIN 2 → A측 하부 출구 → V186 → VIBRO FEEDER #C → EM / 11520-E-MT-18`입니다.

## 워크북 진행 순서

| 순서 | 단원 | 직접 해보는 일 | 남는 결과 |
|---:|---|---|---|
| 1 | 기본: P&ID 입문 | 제목란, 범례, 장비, 선과 태그를 실제 도면에서 찾습니다. | 도면을 읽는 기본 순서 |
| 2 | 기본: 이미지 확대·프롬프트 비교 | 전체 이미지, 상세 프롬프트와 부분 확대 이미지의 결과를 비교합니다. | 모델별 실제 답변과 점수 |
| 3 | 기본: 이미지 입력 전략 | 전체에서 위치를 찾고 필요한 구역을 확대합니다. | 질문에 맞는 이미지 선택 기준 |
| 4 | 기본+선택: OCR와 에이전트 검색 | 준비된 PDF를 검색하고, 원하면 OCR 파일을 직접 만듭니다. | 검색 가능한 PDF와 문자 위치 |
| 5 | 개념+고급 선택: AI 답변을 원본 위치와 연결하기 | 근거 위치를 이해하고, 원하면 bbox 결과 파일을 만듭니다. | 다시 찾을 수 있는 근거 위치 |
| 6 | 선택: P&ID 데이터 정리 | 도면 기본정보, 큰 구역과 주요 태그를 JSON으로 기록합니다. | 검색 가능한 도면 색인 |
| 7 | 기본: AI에게 도면 작업 맡기기 | 목표·입력·규칙·출력·완료 조건을 하나의 요청으로 작성합니다. | 재사용 가능한 업무 요청문 |

## 이 워크북에서 사용하는 파일

| 파일 | 역할 |
|---|---|
| `실습자료/이미지/전체-도면.png` | 도면 전체 구조와 질문 구역의 위치를 찾습니다. |
| `실습자료/이미지/feeder-c-확대.png` | Feeder #C 주변의 작은 태그를 확인합니다. |
| `실습자료/근거-이미지/feeder-c-근거.png` | 답의 근거 위치가 어디인지 확인합니다. |
| `실습자료/ocr/검색가능한-pnid.pdf` | OCR 문자 검색을 실습합니다. |

공개 이미지에서는 회사명, 로고, 주소, 작성자 정보를 마스크로 가렸습니다. PDF를 변환하거나 이미지를 나눌 필요 없이 준비된 파일로 바로 시작할 수 있습니다.

## 결과를 볼 때 기억할 기준

| 확인할 질문 | 이유 |
|---|---|
| 도면에서 직접 읽은 문자열인가요? | 모델의 해석과 실제 표기를 구분합니다. |
| 어떤 선을 따라 연결을 확인했나요? | 가까이 있는 다른 장비의 태그와 섞이지 않게 합니다. |
| 원본의 어느 위치에서 다시 확인할 수 있나요? | 다른 사람이 같은 판단을 검토할 수 있게 합니다. |
| 읽지 못한 값을 추측하지 않았나요? | 자연스럽지만 근거 없는 답을 막습니다. |

이제 [P&ID 입문](01-pnid-기초.md)으로 이동해, AI를 사용하기 전에 사람이 도면을 읽는 순서부터 살펴보겠습니다.
