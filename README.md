# P&ID × AI Agent Workbook

이 프로젝트는 P&ID를 처음 접하는 분을 위한 실습형 워크북입니다. Claude Code와 Codex로 실제 도면을 읽고, 답의 근거를 원본 위치와 연결합니다. 결과를 평가한 뒤 오류 한 가지를 골라 개선하고, 다시 비교하는 과정까지 다룹니다.

공개 워크북은 [GitHub Pages 사이트](https://trillion-labs.github.io/pnid-understanding-bootcamp/)에서 읽을 수 있습니다.

## 워크북의 학습 흐름

```text
도면의 큰 구조를 파악합니다.
        ↓
질문과 관련된 부분을 확대해 작은 글자와 심벌을 확인합니다.
        ↓
AI 답을 원본 위치와 연결합니다.
        ↓
결과를 검색하고 비교할 수 있는 데이터로 정리합니다.
        ↓
같은 기준으로 평가하고 오류 하나를 개선합니다.
```

모든 실습은 아래 질문을 중심으로 이어집니다.

> 이 P&ID에서 `RECEPTION BIN 2`의 A측 하부 출구와 연결된 `VIBRO FEEDER #C`를 찾아 주세요. 도면에 직접 표시된 ① Reception Bin 2의 장비 태그, ② A측 하부 출구의 밸브 번호, ③ Vibro Feeder #C의 장비 태그, ④ Feeder #C에 연결된 전동기의 심벌 표기와 태그를 그대로 적고 연결 관계를 설명해 주세요. 이미지에서 확인되지 않는 값은 추측하지 마세요. 외부 검색, 코드 실행, 줌·OCR 등 도구를 사용하지 말고, 제공된 이미지의 현재 해상도에서 한 번에 답변해 주세요.

기준 답안은 `11520-M-SI-04 → V186 → 11520-M-VB-03C → EM / 11520-E-MT-18`입니다. 이미지에서 이 네 값을 정확히 읽었는지, 연결 관계를 올바르게 따라갔는지를 평가합니다.

## 기준 파일

- 교육용 도면 PDF: `실습자료/ocr/검색가능한-pnid.pdf`
- 도면 식별자: `J-11520-ZM-105-005`, Rev. F
- 전체 구조용 이미지: `실습자료/이미지/전체-도면.png`
- Feeder #C 주변 확대 이미지: `실습자료/이미지/feeder-c-확대.png`
- 질문 근거 위치 예시: `실습자료/근거-이미지/feeder-c-근거.png`
- 검색 가능한 교육용 PDF: `실습자료/ocr/검색가능한-pnid.pdf`

## 비식별 처리

사이트와 공개 저장소의 도면 이미지에는 회사명, 로고, 주소, 작성·검토자 영역을 가리는 불투명 마스크를 적용했습니다. 학습에 필요한 도면 제목, 도면번호, 시트, Rev. F는 남겼습니다.

내부 원본 PDF, 개인 메타데이터가 포함된 export 파일, OCR 원문과 모델의 검토 전 원시 응답은 공개 저장소에 포함하지 않습니다.

## 사이트를 로컬에서 확인하려면

```bash
npm install
npm run dev
```

정적 사이트 빌드와 문서 검색 색인은 다음 명령으로 확인합니다.

```bash
npm run build
```

## 가장 중요한 원칙

AI가 그럴듯하게 말한 값보다 원본 이미지에서 위치를 다시 확인할 수 있는 값을 기록합니다.
