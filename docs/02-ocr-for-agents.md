# Tesseract OCR로 P&ID를 검색 가능하게 만들기

OCR은 에이전트가 큰 도면에서 후보 위치를 빠르게 찾도록 도와줍니다. 하지만 OCR 문자열은 최종 정답이 아닙니다. 이 도면에서는 OCR을 추가하자 한 모델의 점수가 2점에서 4점으로 좋아졌지만, 다른 모델은 3점 그대로였고 밸브 연결을 새롭게 잘못 해석했습니다.

이 단원에서는 OCR이 도움이 되는 부분과 여전히 이미지 검토가 필요한 부분을 실제 결과로 살펴봅니다.

## 텍스트 레이어는 무엇인가요?

원본 `sample-pid.pdf`는 화면에 글자가 보이지만 글자를 선택하거나 검색할 수 없습니다. 글자가 PDF 문자 객체가 아니라 페이지 그림의 일부이기 때문입니다.

Tesseract는 그림 속 글자를 읽고, 원래 위치에 보이지 않는 문자를 겹쳐 넣을 수 있습니다. 이렇게 만든 숨은 문자 정보를 `텍스트 레이어`라고 합니다.

텍스트 레이어가 있으면 에이전트는 다음처럼 문자열로 후보를 좁힐 수 있습니다.

```bash
pdftotext drawing.pdf - | rg -i "VIBRO"
```

이미지 전체를 처음부터 모두 읽는 대신 관련 단어가 있는 부분을 먼저 찾을 수 있다는 점이 가장 큰 장점입니다.

## 왜 `VIBRO`는 검색되는데 `VIBRO FEEDER`는 검색되지 않았을까요?

PDF 검색은 화면에서 글자가 가까이 보이는지가 아니라 OCR이 저장한 문자 순서가 정확히 이어지는지를 봅니다.

기본 OCR 결과에는 다음 형태가 섞여 있었습니다.

```text
VIBROFEEDER
VIBRO,20 FEEDER #D
VIBRO_ FEEDEK
```

사람에게는 모두 Vibro Feeder처럼 보이지만 정확한 문자열 `VIBRO FEEDER`와는 다릅니다.

- 두 단어가 붙어서 한 단어가 되었습니다.
- 쉼표나 밑줄 같은 문자가 중간에 들어갔습니다.
- `FEEDER`의 마지막 `R`이 `K`로 잘못 읽혔습니다.
- 같은 높이에 있는 단어가 서로 다른 OCR 블록으로 나뉘었습니다.

따라서 단어 하나 검색과 구문 검색의 결과가 달라질 수 있습니다.

## 이 도면에서 적용한 네 가지 개선

### 1. P&ID에 맞는 페이지 분할 방식을 사용합니다

Tesseract의 기본 자동 분할 대신 `--psm 6`을 사용했습니다. 이 설정은 정렬된 글자가 많은 현재 도면에서 장비 이름을 한 줄로 묶는 데 도움이 되었습니다.

모든 P&ID에 PSM 6이 항상 맞는 것은 아닙니다. 글자가 사방에 흩어진 도면은 PSM 11이 더 나을 수 있으므로 실제 검색어로 비교해야 합니다.

### 2. 가는 글자를 이진화합니다

`thresholding_method=2`를 사용하여 Sauvola 방식으로 배경과 가는 글자를 분리했습니다. 회색으로 흐릿했던 태그가 더 분명해졌습니다.

### 3. 프로젝트 용어 사전을 제공합니다

`VIBRO`, `FEEDER`, `RECEPTION`, `V186`, 주요 태그를 `data/ocr/pid-user-words.txt`에 넣었습니다. Tesseract가 `FEEDEK`보다 `FEEDER`를 선택할 가능성을 높이기 위한 보조 자료입니다.

### 4. 전체 도면과 부분 확대 이미지를 따로 OCR합니다

전체 도면 OCR은 Reception Bin과 Feeder가 있는 줄을 찾는 데 사용합니다. Feeder #C 주변 확대 OCR은 작은 태그 후보와 위치 좌표를 얻는 데 사용합니다.

한 번의 전체 페이지 OCR로 모든 목적을 해결하려 하지 않습니다.

## 실제 검색 결과는 어떻게 달라졌나요?

| 검색어 | 기존 searchable PDF | 개선 PDF | 좌표 기반 OCR 검색 |
|---|---|---|---|
| `VIBRO FEEDER` | 찾지 못함 | 찾음 | 찾음 |
| `VIBRO FEEDER #C` | 찾지 못함 | 찾지 못함 | 후보 구역을 찾음 |
| `RECEPTION BIN 2` | 찾음 | 정확한 구문 검색은 불안정 | 후보 구역을 찾음 |
| `11520-M-SI-04` | 찾지 못함 | 찾음 | 찾음 |
| `V186` | 찾지 못함 | 찾지 못함 | 찾지 못함 |
| `11520-M-VB-03C` | 찾지 못함 | 찾지 못함 | 정확한 값은 찾지 못함 |
| `11520-E-MT-18` | 찾지 못함 | 찾지 못함 | `f1520-E-MT-18` 후보를 찾음 |

개선된 OCR도 완벽하지 않습니다. 특히 선이 글자를 가로지르는 밸브 번호와 좁은 장비 태그는 계속 어렵습니다.

## OCR이 실제 에이전트 답변에도 도움이 되었나요?

전체 이미지만 사용한 결과와, 같은 전체 이미지에 OCR PDF를 추가한 결과를 비교했습니다. 각 조건은 한 번씩 실행했으므로 일반적인 모델 성능을 주장하는 실험은 아닙니다.

| 모델 | 전체 이미지 | 전체 이미지+OCR | 관찰 |
|---|---:|---:|---|
| Claude Sonnet | 3/4 | 3/4 | 전동기 태그는 맞아졌지만 A측 밸브를 `V183`으로 잘못 연결했습니다. |
| Codex Luna | 2/4 | 4/4 | OCR로 후보를 좁힌 뒤 이미지에서 네 항목을 확인했습니다. |

OCR은 두 모델 모두 문자열 후보를 찾는 데 도움을 주었습니다. 그러나 Claude 사례처럼 글자를 더 많이 확보해도 연결 관계를 잘못 따라갈 수 있습니다.

따라서 역할을 다음처럼 나누는 편이 안전합니다.

```text
OCR 텍스트로 후보 위치를 찾습니다.
        ↓
저장된 좌표로 해당 구역을 크게 봅니다.
        ↓
원본 이미지에서 문자열과 연결을 확인합니다.
        ↓
확인된 값만 최종 답에 사용합니다.
```

## 개선된 OCR 파일을 직접 만들어 봅니다

Tesseract와 Poppler가 설치되어 있다면 다음 명령을 실행합니다.

```bash
./scripts/build-ocr-assets.sh
```

생성되는 주요 파일은 다음과 같습니다.

- `assets/ocr/sample-pid-searchable-improved.pdf`: 검색 가능한 교육용 PDF
- `data/ocr/sample-pid-full-improved.tsv`: 전체 도면의 OCR 문자와 좌표
- `data/ocr/feeder-c-area-improved.tsv`: Feeder #C 확대 이미지의 OCR 문자와 좌표

[개선된 searchable PDF 열기](/pnid-understanding-bootcamp/downloads/sample-pid-searchable-improved.pdf)

## 정확한 구문이 아니어도 후보를 찾습니다

PDF의 정확한 구문 검색이 실패할 때에는 좌표 기반 검색 스크립트를 사용할 수 있습니다.

```bash
python3 scripts/search_ocr.py "VIBRO FEEDER"
```

```bash
python3 scripts/search_ocr.py "RECEPTION BIN 2"
```

```bash
python3 scripts/search_ocr.py "11520-E-MT-18"
```

이 스크립트는 다음 차이를 어느 정도 허용합니다.

- `VIBROFEEDER`처럼 붙은 단어
- 밑줄과 쉼표 같은 중간 문자
- `FEEDEK`처럼 한두 글자가 잘못 읽힌 단어
- 서로 다른 OCR 블록이지만 같은 높이에 있는 단어

결과에는 OCR 문자열과 함께 위치 상자 좌표가 표시됩니다. 점수가 높더라도 최종 값은 이미지를 보고 다시 확인해야 합니다.

## OCR을 더 개선하려면 무엇을 해야 하나요?

다음 순서로 개선하는 것이 효과적입니다.

1. 실제 업무에서 검색할 문구 목록을 먼저 만듭니다.
2. 전체 페이지와 질문 구역을 서로 다른 설정으로 OCR합니다.
3. 프로젝트 장비명과 태그 형식을 사전으로 제공합니다.
4. 정확한 구문 검색뿐 아니라 좌표·토큰 기반 검색을 함께 사용합니다.
5. 반복해서 틀리는 태그는 도메인 규칙으로 후보만 교정합니다.
6. 최종 정답은 항상 원본 이미지에서 검토합니다.

OCR의 목표는 도면을 완벽한 텍스트 문서로 바꾸는 것이 아닙니다. 에이전트가 수많은 글자 가운데 검토할 위치를 더 빨리 찾도록 만드는 것입니다.

다음 단원에서는 OCR이나 모델이 찾은 근거 위치를 다른 사람이 다시 확인할 수 있도록 위치 상자로 저장합니다.
