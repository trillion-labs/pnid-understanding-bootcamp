# 터미널에서 Claude Code와 Codex 실행하기

import TerminalTrainer from '../../../components/TerminalTrainer.astro';

이 단원에서는 준비된 P&ID 이미지와 질문을 터미널에서 직접 실행합니다. 긴 명령을 외울 필요는 없습니다. 먼저 제공된 실행 스크립트를 사용하고, 뒤에서 스크립트 안의 실제 명령을 살펴봅니다.

## 먼저 명령을 직접 타이핑해 봅니다

아래 화면은 명령을 연습하는 시뮬레이터입니다. 실제 Claude나 Codex를 호출하지 않고 컴퓨터의 파일도 변경하지 않습니다. 안내된 명령을 직접 입력하고 `Enter`를 눌러 세 단계를 완료해 보세요.

<TerminalTrainer />

연습을 마쳤다면 바로 아래의 실제 터미널에서 같은 명령을 실행합니다.

## 1. 프로젝트 폴더로 이동합니다

터미널을 열고 다음 명령을 한 줄씩 실행합니다.

```bash
cd ~/Projects/pnid-understanding-bootcamp
pwd
```

`pwd` 결과가 다음처럼 끝나면 올바른 폴더입니다.

```text
/Projects/pnid-understanding-bootcamp
```

다음 명령으로 이미지와 질문 파일이 있는지도 확인합니다.

```bash
ls assets/overview/sample-pid-overview-1600.png
ls assets/regions/feeder-c-area.png
ls experiments/single-image-prompt/prompts/short.txt
```

세 파일명이 그대로 출력되면 준비가 끝났습니다.

## 2. Claude Code와 Codex가 설치되어 있는지 확인합니다

```bash
claude --version
codex --version
```

각 명령에서 버전 번호가 나오면 실행할 수 있습니다. `command not found`가 나오면 해당 CLI를 먼저 설치하고 로그인해야 합니다.

처음 로그인할 때에는 다음처럼 명령만 입력하고 화면 안내를 따르면 됩니다.

```bash
claude
```

```bash
codex
```

로그인을 마쳤다면 `Ctrl+C`를 눌러 대화 화면에서 나옵니다.

## 3. 가장 쉬운 방법으로 한 번 실행합니다

Claude Sonnet에 전체 구조용 이미지를 전달하려면 다음 한 줄을 실행합니다.

```bash
./scripts/run-workbook-cli.sh claude full
```

Codex Luna에 같은 이미지와 질문을 전달하려면 다음 한 줄을 실행합니다.

```bash
./scripts/run-workbook-cli.sh codex-luna full
```

명령을 실행하면 사용한 모델, 이미지, 질문 파일과 결과 저장 위치가 먼저 표시됩니다. 답변이 끝나면 결과는 다음 폴더에 텍스트 파일로 저장됩니다.

```text
output/workbook-cli/
```

원본 이미지와 질문 파일은 수정되지 않습니다. Claude에는 파일 읽기 도구만 허용하고, Codex는 읽기 전용 sandbox로 실행합니다.

## 4. 전체 이미지와 부분 확대 이미지를 비교합니다

다음 여섯 명령을 모두 실행할 필요는 없습니다. 처음에는 같은 모델의 `full`과 `zoom` 두 조건만 비교해도 충분합니다.

### Claude Sonnet

```bash
./scripts/run-workbook-cli.sh claude full
./scripts/run-workbook-cli.sh claude zoom
./scripts/run-workbook-cli.sh claude zoom-guided
```

### Codex Luna

```bash
./scripts/run-workbook-cli.sh codex-luna full
./scripts/run-workbook-cli.sh codex-luna zoom
./scripts/run-workbook-cli.sh codex-luna zoom-guided
```

### Codex Terra

```bash
./scripts/run-workbook-cli.sh codex-terra full
./scripts/run-workbook-cli.sh codex-terra zoom
./scripts/run-workbook-cli.sh codex-terra zoom-guided
```

각 조건의 의미는 다음과 같습니다.

| 조건 | 이미지 | 질문 |
|---|---|---|
| `full` | 전체 구조용 이미지 | 짧은 질문 |
| `zoom` | Feeder #C 주변 확대 이미지 | 짧은 질문 |
| `zoom-guided` | 같은 확대 이미지 | 단계별 확인 질문 |

## 5. 답변을 네 항목으로 확인합니다

저장된 결과 파일을 열어 다음 값을 찾습니다.

| 항목 | 기준 답안 |
|---|---|
| Reception Bin 2 태그 | `11520-M-SI-04` |
| A측 하부 출구 밸브 | `V186` |
| Vibro Feeder #C 태그 | `11520-M-VB-03C` |
| Feeder #C 전동기 | `EM / 11520-E-MT-18` |

각 항목이 정확하면 1점입니다. 전체 이미지와 부분 확대 이미지에서 어느 항목이 달라졌는지 기록해 보세요.

## 실행 스크립트는 어떤 명령을 사용하나요?

스크립트가 대신 실행하는 핵심 명령은 다음과 같습니다. 옵션을 이해하고 싶을 때 참고하면 됩니다.

### Claude Code 명령

```bash
claude -p \
  "Read assets/regions/feeder-c-area.png with the Read tool. Then read experiments/single-image-prompt/prompts/short.txt and answer that Korean prompt. Do not modify files." \
  --model sonnet \
  --effort medium \
  --allowedTools Read \
  --permission-mode dontAsk \
  --no-session-persistence \
  --max-budget-usd 0.30 \
  --output-format text
```

- `-p`는 답변을 출력하고 종료합니다.
- `--allowedTools Read`는 파일 읽기만 허용합니다.
- `--no-session-persistence`는 이 실행을 대화 기록으로 남기지 않습니다.
- `--max-budget-usd 0.30`은 한 번의 실행에 사용할 수 있는 최대 비용을 제한합니다.

### Codex 명령

```bash
codex exec \
  --model gpt-5.6-luna \
  --image assets/regions/feeder-c-area.png \
  --sandbox read-only \
  --ephemeral \
  -C "$PWD" \
  "$(cat experiments/single-image-prompt/prompts/short.txt)"
```

- `codex exec`는 질문을 비대화형으로 실행하고 종료합니다.
- `--image`는 분석할 이미지를 첨부합니다.
- `--sandbox read-only`는 작업 폴더를 읽기 전용으로 사용합니다.
- `--ephemeral`은 세션 파일을 저장하지 않습니다.
- `-C "$PWD"`는 현재 프로젝트 폴더를 작업 기준으로 사용합니다.

Codex CLI의 현재 명령과 옵션은 [공식 OpenAI CLI 명령 문서](https://learn.chatgpt.com/docs/developer-commands?surface=cli)에서도 확인할 수 있습니다.

## 자주 생기는 문제

### `No such file or directory`가 나옵니다

프로젝트 폴더가 아닌 곳에서 실행했을 가능성이 큽니다. 다시 이동합니다.

```bash
cd ~/Projects/pnid-understanding-bootcamp
```

### `command not found: claude` 또는 `command not found: codex`가 나옵니다

해당 CLI가 설치되지 않았거나 터미널 경로에 등록되지 않은 상태입니다. 설치를 확인한 뒤 터미널을 새로 열고 `claude --version` 또는 `codex --version`을 다시 실행합니다.

### 로그인 또는 권한 오류가 나옵니다

`claude` 또는 `codex`만 입력해 로그인 상태를 확인합니다. 조직 계정에서 특정 모델을 사용할 수 없다면 사용할 수 있는 모델 이름으로 바꾸어야 합니다.

### 결과 파일을 찾을 수 없습니다

다음 명령으로 최근 결과를 확인합니다.

```bash
ls -lt output/workbook-cli | head
```

파일명에는 실행 시각, 도구와 조건이 들어 있습니다.

다음 단원에서는 저장된 답변을 네 항목으로 채점하고, 잘못 읽은 값과 확인하지 못한 값을 구분합니다.
