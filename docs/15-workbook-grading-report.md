## 1. 초심자 이해 가능성 — 18/20

### 개선된 점

- Q005를 사용하기 전에 `C번 Vibro Feeder 출구 연결부의 Ash Leak 관련 도면 찾기`라는 쉬운 상황을 설명합니다.
- R03을 먼저 제시하지 않고 `Reception Bin 2와 Feeder #C 주변만 잘라 크게 만든 확대 이미지`라고 설명합니다.
- 프로젝트 내부 ID가 필요한 시점에만 R03이라는 이름을 소개합니다.
- Crop이라는 영문 용어를 핵심 본문에서 제거하고 `부분 확대 이미지`를 사용합니다.
- Evidence, component, unresolved는 각각 근거, 설비 요소, 확인하지 못함이라는 한국어 표현을 먼저 사용합니다.

### 남은 감점 이유

구조화 데이터와 평가 단원에는 데이터 파일의 실제 열 이름을 보여 주기 위해 영문 필드가 남아 있습니다. 본문에서 한국어 설명을 먼저 제공하므로 학습을 막는 수준은 아닙니다.

## 2. 섹션 내부 논리적 연결성 — 19/20

각 섹션은 질문이나 실제 오류에서 시작하고, 문제를 설명한 뒤 개념·자료·해석으로 이어집니다.

특히 이미지 입력 전략 단원은 다음 흐름이 명확합니다.

```text
실제 점수표
→ 부분 확대에서 발생한 문맥 오류
→ 전체와 확대 이미지를 연결해야 하는 이유
→ 이미지 제공 순서
→ 내부 사례
→ 이미지 비용
→ 선택 기준
```

남은 감점은 이미지 비용 부분의 정보 밀도가 다른 섹션보다 높기 때문입니다. 이미지 한 장의 API 비용과 실제 CLI 전체 비용을 별도 제목으로 나누었지만, 공식 규칙 자체가 복잡합니다.

## 3. 용어와 표현의 친절함 — 13/15

### 개선된 점

- 내부 구역 ID와 `crop` 표현 → `Feeder #C 주변을 잘라 크게 만든 확대 이미지`
- `evidence region` → `근거 위치` 또는 `근거 구역`
- `component` → `설비 요소(component)`
- `unresolved` → `확인하지 못함(unresolved)`
- `benchmark` → `평가 세트(benchmark)`
- `gold data` → `사람이 원본을 검토하여 만든 기준 데이터`

데이터 스키마와 파일명을 설명할 때에만 영문 필드를 유지합니다.

### 남은 감점 이유

CLI, API, token, cache, reasoning처럼 제품 사용에 필요한 용어가 비용·재현성 단원에 남아 있습니다. 각 용어를 문맥에서 설명하지만 별도 용어 찾아보기를 추가하면 더 좋습니다.

## 4. 실제성과 근거 품질 — 15/15

- 본문 비교는 Claude Sonnet, Codex Luna, Codex Terra의 실제 새 세션 9회를 사용합니다.
- 이전 Haiku 3회는 raw 부록에만 보존합니다.
- 이미지 조건과 프롬프트 조건을 분리했습니다.
- 실제 성공과 실패 응답을 함께 보여 줍니다.
- Raw output, usage, 수동 검토와 비용 근거를 보존합니다.
- 도면번호 정답과 설비 요소 근거 정답을 분리합니다.
- Trillion Labs 사례의 동일 judge, bias 가능성과 표본 수 미기재를 명시합니다.

## 5. 정보량과 비움의 미학 — 9/10

### 개선된 점

- 실제 CLI 비교는 첫 번째 실험 단원 안에서 3×3 표와 모델별 답변 발췌로 직접 보여 줍니다.
- 이미지 입력 전략과 평가 단원에서는 필요한 점수만 간단한 표로 다시 보여 줍니다.
- Trillion Labs 본문 figure는 네 개 막대와 하나의 메시지만 남겼습니다.
- Haiku 행과 세 번째 관찰 문구를 본문 figure에서 제거했습니다.
- 구조화 데이터 단원은 14개의 논리적 섹션으로 정리했습니다.
- 참가자 선택 실습을 별도 파일로 분리했습니다.

### 남은 감점 이유

P&ID 입문에는 네 장의 이미지가 있습니다. 각 이미지는 단계별 위치·범례·확대·근거를 설명하므로 현재는 필요한 시각 자료로 판단합니다. 향후 인쇄판에서는 페이지 길이를 기준으로 다시 검토할 수 있습니다.

## 6. 직접 따라 할 수 있는 정도 — 9/10

- 준비된 이미지와 searchable PDF가 있습니다.
- 실제 CLI 실행 스크립트와 prompt 원문이 있습니다.
- 모델 실행이 실패해도 준비 응답으로 계속 진행할 수 있습니다.
- 핵심 실습과 선택 확장을 분리했습니다.
- 기록지, raw 결과, 요약 CSV와 자동 검사 스크립트가 있습니다.

남은 감점은 핵심 참가자 안내서가 여전히 긴 편이기 때문입니다. 다만 선택 확장을 분리하여 이전 317줄보다 짧아졌고, 전체 워크북과 빠른 실행 안내의 역할도 구분했습니다.

## 7. 문체와 읽기 경험 — 5/5

- 실제 상황과 질문으로 단원을 시작합니다.
- 짧은 bullet만 나열하지 않고 줄글로 이유와 해석을 설명합니다.
- 단원 마지막에는 다음 활동으로 이어지는 질문을 제공합니다.

## 8. 재현성·비식별·안전성 — 5/5

- 마스크 적용 후 OCR text layer를 다시 생성했습니다.
- 모델, 조건, prompt, raw response와 usage를 보존했습니다.
- Claude CLI 보고 비용과 Codex API 등가 추정 비용을 구분했습니다.
- CSV, JSONL, 이미지 크기, 링크와 스킬 구조 검사가 자동화되어 있습니다.
