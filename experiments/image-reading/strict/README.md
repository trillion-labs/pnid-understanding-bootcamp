# 추가 도구 미사용 2×2 이미지·프롬프트 실험

이 데이터셋은 현재 워크북 본문에 사용하는 `strict-v1` 결과입니다. 2026-09-04에 전체/확대 이미지와 짧은/단계별 프롬프트를 조합한 네 조건을 세 모델에서 한 번씩 실행했습니다.

실행에 사용한 CLI는 Codex CLI 0.151.0과 Claude Code 2.1.260입니다. 모델 별칭은 GPT-5.6 Luna, GPT-5.6 Terra와 Sonnet이며, Claude 원시 결과에는 실제 사용 모델 키도 함께 기록되어 있습니다.

## 고정 조건

- 모든 실행은 이전 대화가 없는 새 일회성 세션입니다.
- 모델별 네 실행에는 같은 모델과 추론 설정을 사용했습니다.
- 지정 이미지를 최초 입력으로 불러온 뒤 추가 파일 읽기, 확대, 자르기, 리사이즈, OCR, 코드 실행과 외부 검색을 금지했습니다.
- 응답은 네 평가 항목만 표로 작성했습니다.
- Codex는 JSONL 이벤트에서 추가 도구 호출이 없음을 확인했습니다. Claude 최종 JSON은 허용된 `Read` 호출 횟수를 제공하지 않으므로 `tool_attempts`를 빈값, `protocol_compliant`를 `limited_trace`로 기록합니다.

## 입력 조건

| 조건 | 이미지 | 프롬프트 |
|---|---|---|
| `full-short` | `전체-도면.png` 1600×1131 | `기본-질문.txt` |
| `full-guided` | `전체-도면.png` 1600×1131 | `단계별-질문.txt` |
| `crop-short` | `feeder-c-확대.png` 1244×1600 | `기본-질문.txt` |
| `crop-guided` | `feeder-c-확대.png` 1244×1600 | `단계별-질문.txt` |

## 채점 규칙

다음 네 항목을 각각 1점으로 채점합니다.

1. Reception Bin 2 태그 `11520-M-SI-04`
2. A측 하부 출구 밸브 `V186`
3. Feeder #C의 Unit 1·2 태그 `11520-M-VB-03C`
4. 전동기 심벌·태그 `EM / 11520-E-MT-18`

도면 글자 간격 때문에 Feeder 태그가 `11520 M-VB-03C`로 전사된 경우는 표준 태그 `11520-M-VB-03C`와 같은 값으로 정규화합니다. 그 밖의 문자나 숫자가 다르면 오답입니다. Unit 1과 Unit 2 중 하나라도 다르면 Feeder 항목은 0점이며, 심벌과 태그 중 하나라도 다르면 전동기 항목은 0점입니다. 추측하지 않고 보류한 답도 문자열을 확인하지 못했으므로 0점입니다.

각 조건을 한 번만 실행했으므로 점수는 성공률이나 모델 순위가 아니라 이번 실행의 관찰값입니다.

원시 결과에서 요약 CSV를 다시 만들 때에는 실제 실행일을 명시합니다.

```bash
python3 scripts/summarize_single_image_prompt_results.py --run-date 2026-09-04
```
