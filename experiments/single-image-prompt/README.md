# 단일 도면 이미지와 프롬프트 비교 실험

현재 본문에서 사용하는 실험은 `deep-reading-v2`입니다. 이미 선택된 P&ID 한 장에서 Feeder #C의 태그, 위·아래 연결과 Expansion Joint 근거를 얼마나 깊게 읽는지 확인합니다.

2. 같은 확대 이미지에서 짧은 질문과 근거 확인 질문을 사용하면 결과가 어떻게 달라집니까?

본문 비교 모델:

- Claude Sonnet
- GPT-5.6 Luna
- GPT-5.6 Terra

실행 조건:

- `full-short`: 전체 도면과 짧은 질문
